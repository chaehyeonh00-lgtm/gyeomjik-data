# 지방의회의원 겸직 신고 데이터

한국데이터저널리즘어워드 출품작 **「'N잡러' 의원님의 이중생활」** 취재에 사용한 지방의회 의원 겸직 신고 자료입니다.
전국 기초의회 의원과 세종·제주 광역의원(두 지역은 기초의회가 없음)이 소속 의회에 신고한 겸직 내역을 한 표로 모았습니다.

> 기사 링크: https://gyeomjik.vercel.app/

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 행 수 | 4,983건 (겸직 1건 = 1행) |
| 의원 수 | 2,002명 (시도·시군구·의원명 기준) |
| 범위 | 16개 시도, 205개 시군구 기초의회 + 세종·제주 광역의회 |
| 신고 시점 | 대부분 2026년 6~7월 신고분 |
| 파일 | `gyeomjik-all.csv` (UTF-8) |

의원 한 명이 겸직을 여러 개 신고했으면 여러 행으로 나뉩니다. 의원별 집계를 하려면 `시도 + 시군구 + 의원명`으로 묶으세요. 의원명만으로 묶으면 동명이인이 섞입니다.

## 출처와 수집 방법

- **원출처**: 각 지방의회 홈페이지 겸직 신고 공개 자료 / 정보공개청구 회신 자료
- **수집 기간**: 2026년 8월 20일 ~ 10월 22일
- **가공 내용**: 의회별로 서식이 달라 공통 컬럼으로 맞췄습니다. 회사명·직위·재직기간·보수액은 **의회가 공개한 문구를 원문 그대로** 옮겼고, 표기 통일은 하지 않았습니다(아래 '쓰기 전에 알아둘 점' 참고).

## 컬럼 설명

| 컬럼 | 설명 | 값 예시 |
|---|---|---|
| `시도` | 의회가 속한 광역자치단체 | 강원특별자치도, 전남광주통합특별시 |
| `시군구` | 기초의회 소재 시군구. 광역의원(세종·제주)은 `-` | 강릉시, `-` |
| `지역구` | 의원의 선거구. 비례대표는 시군구명(기초) 또는 시도명(광역) | 강릉시마선거구, 제1선거구 |
| `기초/광역` | 의회 구분과 비례대표 여부 | 기초, 기초(비례), 광역, 광역(비례) |
| `의원명` | 의원 이름 | |
| `정당` | 소속 정당(신고 시점 기준) | 더불어민주당, 국민의힘, 무소속 |
| `시군구(원본)` | 원자료에 적힌 선거구 표기. 기초는 가·나·다 등 선거구 기호, 세종은 숫자, 제주는 읍면동 선거구명, 비례대표는 `비례` | 가, 비례, 제주시화북동 |
| `재선 여부` | 해당 의회에서 처음 당선됐는지 여부 | 초임, 재선 |
| `회사명` | 겸직하는 기관·단체·업체 이름. 개인사업은 업종만 적힌 경우도 있음 | 민주평화통일자문회의, 부동산 임대업 |
| `직위` | 겸직처에서 맡은 직위 | 대표, 위원, 자문위원 |
| `재직기간` | 겸직 시작~종료 시점. 원문 표기 그대로 | 2025.5.~, 2017.7.14.~2026.8.12. |
| `보수수령여부` | 겸직으로 보수를 받는지 | 수령, 미수령, 확인불가, 비공개 |
| `(신고)보수액` | 의원이 신고한 보수액. 신고한 단위(연·월·회당) 그대로 적음 | 연 2,500만원 |
| `수령액` | `(신고)보수액`을 연간 금액으로 환산한 값. | 25000000 |
| `신고일` | 의회에 겸직을 신고한 날짜. 원문 표기 그대로 | 2026.6.25, 2026.7. |

`비공개`는 의회가 해당 항목을 가리고 공개한 경우, `확인불가`는 공개 자료에 해당 내용이 없거나 판독할 수 없는 경우입니다.
`보수수령여부`를 `수령`으로 표기했지만 `수령액`이 0원 혹은 비어있는 경우는 그대로 정리했습니다.
다만 신고한 `보수수령여부`가 `미수령`이더라도 `수령액`이 있으면 수령으로 표기해 정리했습니다.

## 쓰기 전에 알아둘 점

- **같은 단체도 표기가 제각각입니다.** 예를 들어 민주평화통일자문회의는 `제22기 민주평화통일자문회의`, `민주평화통일 자문회의`, `민주평화통일자문회의 ○○협의회` 등으로 적혀 있습니다. 이는 신고서 원문을 존중하기 위한 표기이므로, 단체별로 집계하려면 먼저 이름을 정규화하시기 바랍니다.
- **`수령액`에는 숫자가 아닌 값이 섞여 있습니다.** `비공개`(135건), `확인불가`(15건), `회당 8만원`처럼 회당 금액으로 적힌 경우(4건)가 있습니다. 숫자로 변환할 때 이 값들은 따로 처리하세요.
- **`보수수령여부`가 `수령`인데 `수령액`이 빈 행**이 134건 있습니다. 금액을 공개하지 않았거나 신고서에 금액이 없는 경우입니다.
- **음수 금액이 3건** 있습니다. 개인사업 결손 등으로 신고된 값을 그대로 옮긴 것입니다.
- **수억 원대 금액**은 대부분 개인사업체 소득을 신고한 경우입니다. 위원회 수당 같은 보수와는 성격이 다르니 평균을 낼 때 주의하세요.
- **`재직기간`, `신고일`은 날짜 형식이 통일돼 있지 않습니다**(`2026.7.`, `2026. 7`, `2026.07` 등). 날짜로 분석하려면 정규화가 필요합니다.
- `.xlsx` 파일의 `지역구`, `기초/광역`, `(신고)보수액`은 수식으로 계산된 값입니다. `.csv`에는 계산된 결과만 들어 있습니다.
